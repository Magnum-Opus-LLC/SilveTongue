# Learning Schedule

This directory contains learning schedules for the actor. Each schedule defines:
- A source directory containing papers/articles to study
- Study parameters (depth, focus areas, output format)
- Progress tracking

## Structure

```
learning_schedule/
├── schedules/           # Individual schedule definitions
│   └── example.json     # Schedule configuration
├── notes/               # Generated study notes
│   └── {schedule_name}/ # Notes per schedule
├── knowledge/           # Extracted knowledge bits
│   └── {schedule_name}/ # Knowledge per schedule
└── README.md
```

## Schedule Format

See `schedules/example.json` for the schema.
