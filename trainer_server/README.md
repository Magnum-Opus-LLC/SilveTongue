# Silvertongue LoRA Training Server

A distributed training server for running LoRA fine-tuning jobs on a GPU machine (e.g., NVIDIA DGX Spark) while the main Silvertongue application runs on a separate machine.

## Architecture

```
┌─────────────────────┐         ┌─────────────────────┐
│   Mac (Worker)      │         │   DGX Spark (GPU)   │
│                     │         │                     │
│  ┌───────────────┐  │   NAS   │  ┌───────────────┐  │
│  │  Silvertongue │  │◄───────►│  │ Trainer Server│  │
│  │   Dashboard   │  │  Shared │  │   (LoRA)      │  │
│  └───────────────┘  │  Files  │  └───────────────┘  │
│                     │         │                     │
│  - Chat with actors │         │  - GPU Training     │
│  - Learning cycles  │         │  - Model serving    │
│  - Sleep (gen data) │         │  - Adapter storage  │
└─────────────────────┘         └─────────────────────┘
```

## Setup on DGX Spark

### 1. Mount NAS Share

Make sure the NAS share is mounted on both machines at a consistent path:

```bash
# Example: Mount NAS on DGX Spark
sudo mount -t nfs nas.local:/silvertongue /mnt/nas/silvertongue
```

### 2. Install Dependencies

```bash
# Create conda environment
conda create -n silvertongue-trainer python=3.11
conda activate silvertongue-trainer

# Install PyTorch with CUDA (adjust for your CUDA version)
conda install pytorch pytorch-cuda=12.1 -c pytorch -c nvidia

# Install other dependencies
pip install -r requirements.txt
```

### 3. Configure Environment

```bash
# Set environment variables
export SILVERTONGUE_DATA_DIR=/mnt/nas/silvertongue/array
export SILVERTONGUE_OUTPUT_DIR=/mnt/nas/silvertongue/models
export SILVERTONGUE_BASE_MODEL=meta-llama/Llama-3.2-3B-Instruct

# Or use command line arguments when starting
```

### 4. Start the Server

```bash
# Basic start
python server.py

# With custom config
python server.py \
    --host 0.0.0.0 \
    --port 5050 \
    --data-dir /mnt/nas/silvertongue/array \
    --output-dir /mnt/nas/silvertongue/models \
    --base-model meta-llama/Llama-3.2-3B-Instruct
```

### 5. Run as Service (Optional)

Create a systemd service for automatic startup:

```bash
sudo tee /etc/systemd/system/silvertongue-trainer.service << EOF
[Unit]
Description=Silvertongue LoRA Training Server
After=network.target

[Service]
Type=simple
User=$USER
WorkingDirectory=/path/to/silvertongue/trainer_server
Environment="SILVERTONGUE_DATA_DIR=/mnt/nas/silvertongue/array"
Environment="SILVERTONGUE_OUTPUT_DIR=/mnt/nas/silvertongue/models"
ExecStart=/home/$USER/miniconda3/envs/silvertongue-trainer/bin/python server.py
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable silvertongue-trainer
sudo systemctl start silvertongue-trainer
```

## API Endpoints

### Health Check
```bash
GET /health

# Response
{
    "status": "healthy",
    "gpu_available": true,
    "current_job": null,
    "queued_jobs": 0
}
```

### Submit Training Job
```bash
POST /api/train
Content-Type: application/json

{
    "actor_name": "steve",
    "base_model": "meta-llama/Llama-3.2-3B-Instruct",
    "lora_r": 16,
    "lora_alpha": 32,
    "num_epochs": 3,

    "learning_rate": 0.0002
}
```

### Check Job Status
```bash
GET /api/jobs/{job_id}
```

### List All Jobs
```bash
GET /api/jobs
```

### List Trained Models
```bash
GET /api/models
```

## Connecting from Mac

Update the Silvertongue config to point to the trainer server:

```json
{
    "trainer_server": {
        "host": "dgx-spark.local",
        "port": 5050
    }
}
```

Then from the dashboard or code:

```python
import requests

# Submit training job after sleep
response = requests.post(
    "http://dgx-spark.local:5050/api/train",
    json={"actor_name": "steve"}
)
print(response.json())
```

## Supported Base Models

- `meta-llama/Llama-3.2-3B-Instruct` (recommended for Spark)
- `meta-llama/Llama-3.2-1B-Instruct` (lighter)
- `mistralai/Mistral-7B-Instruct-v0.3`
- `Qwen/Qwen2.5-7B-Instruct`
- Any Hugging Face causal LM model

## Training Data Format

The server expects training data in JSONL format (Alpaca style):

```jsonl
{"instruction": "...", "input": "...", "output": "..."}
{"instruction": "...", "input": "...", "output": "..."}
```

This is automatically generated by the Silvertongue sleep cycle.

## Output

Trained adapters are saved to:
```
{output_dir}/{actor_name}/{job_id}/adapter/
├── adapter_config.json
├── adapter_model.safetensors
└── training_info.json
```

## Loading Trained Adapter

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

# Load base model
base_model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")
tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-3.2-3B-Instruct")

# Load adapter
model = PeftModel.from_pretrained(base_model, "/path/to/adapter")

# Use the personalized model
inputs = tokenizer("What are your core values?", return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=200)
print(tokenizer.decode(outputs[0]))
```
